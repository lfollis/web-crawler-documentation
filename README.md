# Website Content Audit Crawler

A Python-based website crawler designed to audit large websites for specific text references.

## Features

- Full-domain crawling
- Sitemap ingestion
- PDF scanning
- Iframe scanning
- JavaScript rendering with Playwright
- Excel report generation

## Technologies

- Python
- Playwright
- BeautifulSoup
- PyMuPDF
- Pandas

## Use Cases

- Compliance audits
- Content reviews
- Brand mention detection
- Legacy content cleanup
